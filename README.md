# 📌 Projetos em destaque

## 🚚 Elo Logística

Plataforma para **gestão de logística e entregas**, contemplando recursos como:

- Cadastro e gerenciamento de entregas
- Planejamento de rotas
- Rastreamento de entregadores
- Atualização de localização em tempo real
- Estimativa de chegada (ETA)
- Integração com serviços de mapas
- Aplicação web e mobile

**Tecnologias e conceitos:** PHP, MySQL, APIs, mapas, geolocalização, arquitetura de sistemas e otimização de rotas.

---

## 🦺 ErgoEasy

Sistema voltado para **análise ergonômica do trabalho**, apoiando processos relacionados à avaliação das condições de trabalho.

Entre os conceitos envolvidos:

- Cadastro de empresas
- Setores e cargos
- Trabalhadores
- Avaliações ergonômicas
- Questionários
- Registro de informações
- Fotografias e evidências
- Relatórios
- Banco de dados estruturado
- Documentação técnica

**Tecnologias:** PHP, MySQL, HTML, CSS, Bootstrap e JavaScript.

# 📚 Filosofia de desenvolvimento

> **Tecnologia deve resolver problemas reais.**

Meu objetivo ao desenvolver sistemas é combinar:

**Problema → Requisitos → Modelagem → Desenvolvimento → Testes → Documentação → Evolução**

Acredito que um bom software não é apenas aquele que funciona, mas aquele que é **compreensível, sustentável, seguro e capaz de evoluir**.
